# منظّم المهام الدراسية

مشروع تطبيقي بسيط لمقرر مهارات الحاسوب، يوضح أساسيات بناء صفحة ويب باستخدام **HTML وCSS وJavaScript**.

## فكرة المشروع

تطبيق يساعد الطالب على تنظيم مهامه الدراسية ومتابعة ما أنجزه.

## المميزات

- إضافة مهمة جديدة.
- تحديد المهمة كمكتملة أو إعادتها إلى قيد التنفيذ.
- حذف مهمة واحدة أو حذف جميع المهام المكتملة.
- عرض عدد المهام الكلي والمكتملة والمتبقية.
- حفظ المهام تلقائياً في المتصفح باستخدام `localStorage`.
- واجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار وتتناسب مع الهاتف.

## ملفات المشروع

- `index.html`: هيكل الصفحة.
- `style.css`: التنسيق والألوان والتصميم المتجاوب.
- `app.js`: وظائف إضافة المهام وتحديثها وحفظها.

## طريقة التشغيل

1. نزّل ملفات المشروع أو استنسخ المستودع.
2. افتح ملف `index.html` في متصفح الويب.
3. أضف مهامك وجرّب أزرار الإكمال والحذف.

## التقنيات المستخدمة

HTML5, CSS3, JavaScript (Vanilla JS), Local Storage.
